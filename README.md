# Gruppe 20 – Bachelor-profileringsside

Velkommen til Gruppe 20 sin bachelor-profileringsside!

Vi er seks studenter som studerer Bachelor i IT og informasjonssystemer ved Universitetet i Agder. Nettsiden fungerer som en digital presentasjon av gruppen, hvor potensielle samarbeidspartnere og bedrifter kan bli bedre kjent med oss, våre interesser, erfaringer og ferdigheter.

## Live nettside

https://gruppe20-is-310.vercel.app

## Teknologier brukt

| Teknologi | Formål |
|-----------|--------|
| React | Frontend-rammeverk for å bygge nettsiden |
| TypeScript | Type-sikker utvikling |
| Vite | Utviklingsserver og build-verktøy |
| CSS | Styling og layout |
| Vercel | Hosting og deployment |

## Kom i gang

Følg stegene under for å kjøre prosjektet lokalt.

### 1. Klon repositoryet
```bash
git clone https://github.com/amged002/Gruppe20-IS-310.git
cd Gruppe20-IS-310

### 2. Installer avhengigheter
```bash
npm install

### 3. Bygge prosjektet
```bash
npm run build

### 4. Start utviklingsserveren
```bash
npm run dev

Nettsiden vil nå være tilgjengelig på:
http://localhost:5173

Deployment
Prosjektet er deployet gjennom Vercel og koblet til GitHub-repositoryet.
